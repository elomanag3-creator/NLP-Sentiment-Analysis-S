🌐 USING THE API

Start Flask API Server:
───────────────────────
  python api.py

Expected output:
  * Running on http://localhost:5000


Predict on single review (in new terminal):
────────────────────────────────────────────
  curl -X POST http://localhost:5000/api/v1/predict \
    -H "Content-Type: application/json" \
    -d '{"review": "This product is amazing!"}'

Example response:
  {
    "status": "success",
    "review": "This product is amazing!",
    "sentiment": "Positive",
    "confidence": 0.94,
    "probabilities": {
      "negative": 0.06,
      "positive": 0.94
    }
  }


Batch predictions (multiple reviews):
──────────────────────────────────────
  curl -X POST http://localhost:5000/api/v1/predict-batch \
    -H "Content-Type: application/json" \
    -d '{"reviews": ["Great!", "Terrible", "Amazing product"]}'


Get model info:
───────────────
  curl http://localhost:5000/api/v1/model-info

📚 UNDERSTANDING THE CODE

Text Preprocessing (src/preprocess.py):
────────────────────────────────────────
TextPreprocessor class:
  • clean_text() → Lowercase, remove special chars, tokenize
  • fit_vectorizer() → Create TF-IDF features
  • transform() → Convert new text to features

Key insight: Text → Numbers via TF-IDF (Term Frequency-Inverse Document Frequency)


Model Training (src/train.py):
──────────────────────────────
SentimentModel class:
  • build_ensemble() → Create Logistic Regression + XGBoost voting ensemble
  • train() → Fit model on training data
  • cross_validate() → 5-fold cross-validation
  • evaluate() → Test set performance
  • predict() → Make predictions

Key insight: Ensemble = Multiple models voting for better predictions


Predictions (src/predict.py):
────────────────────────────
SentimentPredictor class:
  • predict_single() → Predict sentiment for one review
  • predict_batch() → Predict for multiple reviews
  • predict_from_file() → Predict from CSV file

Key insight: Reuse preprocessor + model for consistent predictions


Analysis & Visualization (src/analysis.py):
───────────────────────────────────────────
ResultsAnalyzer class:
  • plot_confusion_matrix() → Show correct/incorrect predictions
  • plot_roc_curve() → Model performance curve
  • plot_metrics_comparison() → Compare all metrics
  • generate_report() → Text report of results

Key insight: Visualizations help understand model behavior

🐛 TROUBLESHOOTING

Issue: "ModuleNotFoundError: No module named 'sklearn'"
Solution: pip install -r requirements.txt

Issue: "FileNotFoundError: data/reviews.csv"
Solution: Make sure you're in the NLP_Project/ directory

Issue: "NLTK data not found"
Solution: python -c "import nltk; nltk.download('punkt'); nltk.download('stopwords')"

Issue: "Model training is slow"
Solution: Reduce max_features in src/config.py (try 50 instead of 100)

Issue: "Port 5000 already in use"
Solution: Change port in src/config.py API_CONFIG or stop other Flask apps
